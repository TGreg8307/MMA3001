occvent.sensitivity

Sensitivity and uncertainty analysis of the ventilation results.

The model inputs that cannot be measured from the data are uncertain:

  • the room volume V (estimated);
  • the CO2 generation rate per person G (literature range);
  • the outdoor CO2 concentration C_out (assumed);
  • a systematic people-counter error, a factor k on every count.

This module provides two taught approaches:

  1. One-at-a-time (OAT) perturbation (oat_sensitivity(), elasticities()). Move one input while holding the others at their nominal values, and record the change in an output. The results are shown as a tornado chart.
  2. Monte Carlo uncertainty propagation (sample_inputs(), percentile_summary()). Draw all inputs at random from assumed distributions, evaluate the output for every draw, and report the spread.

Exact scaling law (why Monte Carlo is cheap here)

The CO2 model is linear. Write C = C_out + Y with Y(0) = 0 (the room starts at outdoor level). With the counts scaled by k::

V dY/dt = 1e6 G k N(t) - Q Y.

Let Z solve the same equation for a unit room (V = 1, G = 1, k = 1, C_out = 0) with flow a = Q / V::

dZ/dt = 1e6 N(t) - a Z.

Substituting Y = (k G / V) Z satisfies the first equation exactly. So every positively homogeneous metric (8-hour mean maximum, peak) satisfies::

metric(V, G, C_out, k, Q) = C_out + (k G / V) * M(Q / V),

where M(a) is the metric of the unit room. All four inputs collapse onto one curve of one variable, the volume-specific flow a = Q / V. Consequences:

  • G and k enter only as their product: a 10 % sensor over-count has exactly the same effect as a 10 % higher CO2 generation rate.
  • Q_min solves M(a) = (limit - C_out) V / (k G), then Q_min = a V. So it needs only an inversion of the tabulated M(a) (ResponseCurve), not a new set of ODE solves for every sample.

The curve is tabulated once with the exact solver. It is inverted by piecewise-linear interpolation in log-log coordinates (Week 3), and the result is checked against full root finding in the notebook.

 79def scaled_metric(
 80    unit_value: np.ndarray | float,
 81    volume_m3: np.ndarray | float,
 82    co2_generation_lps: np.ndarray | float,
 83    outdoor_co2_ppm: np.ndarray | float,
 84    count_factor: np.ndarray | float = 1.0,
 85) -> np.ndarray:
 86    """Map a unit-room metric ``M(a)`` to a real room: ``C_out + (k G / V) M``.
 87
 88    Valid for metrics that scale linearly with ``C - C_out``: the worst
 89    8-hour mean, the peak and the mean. It is **not** valid for "fraction of
 90    time above a limit". Arrays broadcast.
 91
 92    Parameters
 93    ----------
 94    unit_value : float or array_like
 95        Metric of the unit room, ``M(a)``.
 96    volume_m3, co2_generation_lps, outdoor_co2_ppm : float or array_like
 97        ``V`` [m3], ``G`` [L/s per person] and ``C_out`` [ppm] of the real room.
 98    count_factor : float or array_like, default 1.0
 99        ``k``: true occupancy divided by counted occupancy.
100
101    Returns
102    -------
103    numpy.ndarray
104        The metric of the real room [ppm].
105    """
106    return np.asarray(outdoor_co2_ppm) + (np.asarray(count_factor) * np.asarray(co2_generation_lps)
107                                         / np.asarray(volume_m3)) * np.asarray(unit_value)

110@dataclass
111class ResponseCurve:
112    """Tabulated unit-room metrics ``M(a)`` for one occupancy record.
113
114    Build it with :meth:`build`. Then :meth:`metric` and :meth:`q_min` give
115    the worst 8-hour mean, the peak and ``Q_min`` for any ``(V, G, C_out, k)``
116    without further ODE solves.
117
118    Attributes
119    ----------
120    a : numpy.ndarray
121        Volume-specific flows ``Q/V`` [(L/s)/m3], strictly increasing.
122    values : dict of str to numpy.ndarray
123        ``{"8h": M_8h(a), "peak": M_peak(a)}``: unit-room metrics, strictly
124        decreasing in ``a``.
125    """
126
127    a: np.ndarray
128    values: dict[str, np.ndarray]
129
130    @classmethod
131    def build(
132        cls,
133        occupancy: np.ndarray,
134        dt_s: float,
135        a_grid: np.ndarray | None = None,
136    ) -> ResponseCurve:
137        """Tabulate ``M(a)`` with one exact solve per grid point.
138
139        Parameters
140        ----------
141        occupancy : array_like
142            People per step (at least 8 hours, not all zero).
143        dt_s : float
144            Step length [s].
145        a_grid : array_like, optional
146            Flows ``Q/V`` [(L/s)/m3]. Defaults to 81 log-spaced values from
147            0.05 to 10, i.e. 0.18–36 air changes per hour.
148
149        Returns
150        -------
151        ResponseCurve
152
153        Raises
154        ------
155        ValueError
156            If the grid is not positive and strictly increasing, or the
157            tabulated metrics are not strictly decreasing (for example, an
158            empty room).
159        """
160        a = np.geomspace(0.05, 10.0, 81) if a_grid is None else np.asarray(a_grid, dtype=np.float64)
161        if a.ndim != 1 or a.size < 2 or np.any(a <= 0) or np.any(np.diff(a) <= 0):
162            raise ValueError("a_grid must be 1-D, positive and strictly increasing with >= 2 points")
163        keys = {name: key for name, (key, _) in CRITERIA.items()}
164        rows = [evaluate_ventilation(occupancy, float(ai), UNIT_ROOM, dt_s) for ai in a]
165        values = {name: np.array([r[key] for r in rows]) for name, key in keys.items()}
166        for name, v in values.items():
167            if not (np.all(v > 0) and np.all(np.diff(v) < 0)):
168                raise ValueError(f"tabulated {name} metric is not positive and strictly decreasing")
169        return cls(a=a, values=values)
170
171    def _check(self, criterion: str) -> np.ndarray:
172        if criterion not in self.values:
173            raise ValueError(f"criterion must be one of {sorted(self.values)}, got {criterion!r}")
174        return self.values[criterion]
175
176    def metric(
177        self,
178        criterion: str,
179        ventilation_lps: np.ndarray | float,
180        volume_m3: np.ndarray | float,
181        co2_generation_lps: np.ndarray | float,
182        outdoor_co2_ppm: np.ndarray | float,
183        count_factor: np.ndarray | float = 1.0,
184    ) -> np.ndarray:
185        """Metric [ppm] for constant flow ``Q``, interpolating ``log M`` against ``log a``.
186
187        Parameters
188        ----------
189        criterion : {"8h", "peak"}
190            Which metric.
191        ventilation_lps : float or array_like
192            Constant flow ``Q`` [L/s].
193        volume_m3, co2_generation_lps, outdoor_co2_ppm, count_factor
194            As for :func:`scaled_metric`. Arrays broadcast.
195
196        Returns
197        -------
198        numpy.ndarray
199            Worst 8-hour mean or peak CO2 [ppm].
200
201        Raises
202        ------
203        ValueError
204            If any ``Q/V`` lies outside the tabulated range (no extrapolation).
205        """
206        v = self._check(criterion)
207        a = np.asarray(ventilation_lps, dtype=np.float64) / np.asarray(volume_m3, dtype=np.float64)
208        if np.any(a < self.a[0]) or np.any(a > self.a[-1]):
209            raise ValueError(f"Q/V outside the tabulated range [{self.a[0]:.3g}, {self.a[-1]:.3g}]")
210        m = np.exp(np.interp(np.log(a), np.log(self.a), np.log(v)))
211        return scaled_metric(m, volume_m3, co2_generation_lps, outdoor_co2_ppm, count_factor)
212
213    def q_min(
214        self,
215        criterion: str,
216        volume_m3: np.ndarray | float,
217        co2_generation_lps: np.ndarray | float,
218        outdoor_co2_ppm: np.ndarray | float,
219        count_factor: np.ndarray | float = 1.0,
220        limit_ppm: float | None = None,
221    ) -> np.ndarray:
222        """Minimum constant flow ``Q_min`` [L/s] for each set of inputs (arrays broadcast).
223
224        Solves ``M(a) = (limit - C_out) V / (k G)`` by inverse interpolation of
225        the tabulated, strictly decreasing ``M(a)``, then ``Q_min = a V``.
226
227        Parameters
228        ----------
229        criterion : {"8h", "peak"}
230            Which metric must meet its limit.
231        volume_m3, co2_generation_lps, outdoor_co2_ppm, count_factor
232            As for :func:`scaled_metric`. Arrays broadcast.
233        limit_ppm : float, optional
234            Overrides the criterion's default limit (850 or 1000 ppm).
235
236        Returns
237        -------
238        numpy.ndarray
239            ``Q_min`` [L/s] for each set of inputs.
240
241        Raises
242        ------
243        ValueError
244            If ``limit <= C_out`` for any sample, or the required ``M`` lies
245            outside the tabulated range (no extrapolation).
246        """
247        v = self._check(criterion)
248        limit = CRITERIA[criterion][1] if limit_ppm is None else float(limit_ppm)
249        c_out = np.asarray(outdoor_co2_ppm, dtype=np.float64)
250        if np.any(c_out >= limit):
251            raise ValueError("the limit must exceed the outdoor CO2 concentration")
252        target = (limit - c_out) * np.asarray(volume_m3) / (np.asarray(count_factor) * np.asarray(co2_generation_lps))
253        if np.any(target > v[0]) or np.any(target < v[-1]):
254            raise ValueError("required unit metric outside the tabulated range; widen a_grid")
255        # np.interp needs increasing x: M is decreasing, so reverse both arrays.
256        log_a = np.interp(np.log(target), np.log(v[::-1]), np.log(self.a[::-1]))
257        return np.exp(log_a) * np.asarray(volume_m3, dtype=np.float64)

264def oat_sensitivity(
265    f: Callable[..., float],
266    nominal: Mapping[str, float],
267    ranges: Mapping[str, tuple[float, float]],
268) -> pd.DataFrame:
269    """One-at-a-time sensitivity of ``f`` over a low/high range for each input.
270
271    Parameters
272    ----------
273    f : callable
274        ``f(**inputs) -> float``. Called with every key of ``nominal``.
275    nominal : mapping
276        Nominal value of every input.
277    ranges : mapping
278        ``{name: (low, high)}`` for the inputs to vary (a subset of ``nominal``).
279
280    Returns
281    -------
282    pandas.DataFrame
283        One row per varied input, sorted by decreasing swing, with columns
284        ``parameter``, ``low``, ``high``, ``f_low``, ``f_high``, ``f_nominal``
285        and ``swing = |f_high - f_low|``. This is the data for a tornado chart.
286
287    Raises
288    ------
289    KeyError
290        If a range is given for an input that is not in ``nominal``.
291    """
292    unknown = set(ranges) - set(nominal)
293    if unknown:
294        raise KeyError(f"ranges given for unknown inputs: {sorted(unknown)}")
295    f0 = float(f(**nominal))
296    rows = []
297    for name, (lo, hi) in ranges.items():
298        f_lo = float(f(**{**nominal, name: lo}))
299        f_hi = float(f(**{**nominal, name: hi}))
300        rows.append({"parameter": name, "low": lo, "high": hi, "f_low": f_lo, "f_high": f_hi,
301                     "f_nominal": f0, "swing": abs(f_hi - f_lo)})
302    return pd.DataFrame(rows).sort_values("swing", ascending=False, kind="stable", ignore_index=True)

305def elasticities(
306    f: Callable[..., float],
307    nominal: Mapping[str, float],
308    names: list[str] | None = None,
309    rel_step: float = 0.01,
310) -> dict[str, float]:
311    """Normalised local sensitivities ``(x / f) df/dx`` by central differences.
312
313    An elasticity of ``e`` means a 1 % change in the input changes the output
314    by about ``e`` %. Inputs with very different units can then be compared.
315    For a power law ``f = c x^p`` the elasticity is ``p``; the central
316    difference has an ``O(rel_step^2)`` error.
317
318    Parameters
319    ----------
320    f : callable
321        ``f(**inputs) -> float``.
322    nominal : mapping
323        Nominal inputs (non-zero for the inputs differentiated).
324    names : list of str, optional
325        Inputs to differentiate. Defaults to all of ``nominal``.
326    rel_step : float, default 0.01
327        Relative perturbation ``h``: inputs are set to ``x (1 +/- h)``.
328
329    Returns
330    -------
331    dict of str to float
332        Elasticity of ``f`` with respect to each input in ``names``.
333
334    Raises
335    ------
336    ValueError
337        If ``rel_step`` is not in (0, 0.5), or ``f`` or an input is zero at
338        the nominal point.
339    """
340    if not 0 < rel_step < 0.5:
341        raise ValueError("rel_step must be in (0, 0.5)")
342    f0 = float(f(**nominal))
343    if f0 == 0:
344        raise ValueError("f is zero at the nominal point; elasticity undefined")
345    out = {}
346    for name in names or list(nominal):
347        x = float(nominal[name])
348        if x == 0:
349            raise ValueError(f"input {name!r} is zero; elasticity undefined")
350        f_up = float(f(**{**nominal, name: x * (1 + rel_step)}))
351        f_dn = float(f(**{**nominal, name: x * (1 - rel_step)}))
352        out[name] = (f_up - f_dn) / (2 * rel_step * f0)
353    return out

360def sample_inputs(
361    distributions: Mapping[str, tuple],
362    n: int,
363    seed: int | None = 0,
364) -> dict[str, np.ndarray]:
365    """Draw ``n`` independent samples of each input.
366
367    Parameters
368    ----------
369    distributions : mapping
370        ``{name: (kind, *params)}`` with ``kind`` one of
371        ``("uniform", low, high)``, ``("loguniform", low, high)``,
372        ``("triangular", low, mode, high)`` or ``("normal", mean, sd)``.
373    n : int
374        Number of samples (> 0).
375    seed : int or None, default 0
376        Seed of :func:`numpy.random.default_rng`, for reproducibility.
377
378    Returns
379    -------
380    dict of str to numpy.ndarray
381
382    Raises
383    ------
384    ValueError
385        For an unknown distribution, the wrong number of parameters, or
386        invalid parameters.
387    """
388    if not isinstance(n, (int, np.integer)) or n < 1:
389        raise ValueError(f"n must be a positive integer, got {n!r}")
390    rng = np.random.default_rng(seed)
391    out = {}
392    for name, spec in distributions.items():
393        kind, *p = spec
394        if kind not in DISTRIBUTIONS:
395            raise ValueError(f"{name}: unknown distribution {kind!r}; use one of {sorted(DISTRIBUTIONS)}")
396        if len(p) != len(DISTRIBUTIONS[kind]):
397            raise ValueError(f"{name}: {kind} needs parameters {DISTRIBUTIONS[kind]}, got {p}")
398        if kind in ("uniform", "loguniform") and not p[0] < p[1]:
399            raise ValueError(f"{name}: need low < high")
400        if kind == "loguniform":
401            if p[0] <= 0:
402                raise ValueError(f"{name}: loguniform needs low > 0")
403            out[name] = np.exp(rng.uniform(np.log(p[0]), np.log(p[1]), n))
404        elif kind == "uniform":
405            out[name] = rng.uniform(p[0], p[1], n)
406        elif kind == "triangular":
407            if not p[0] <= p[1] <= p[2] or p[0] == p[2]:
408                raise ValueError(f"{name}: need low <= mode <= high and low < high")
409            out[name] = rng.triangular(p[0], p[1], p[2], n)
410        else:
411            if p[1] <= 0:
412                raise ValueError(f"{name}: normal needs sd > 0")
413            out[name] = rng.normal(p[0], p[1], n)
414    return out

417def percentile_summary(values: np.ndarray, percentiles: tuple[float, ...] = (5, 50, 95)) -> dict[str, float]:
418    """Mean, standard deviation, standard error of the mean and percentiles of a sample.
419
420    The standard error ``sd / sqrt(n)`` shows the ``1/sqrt(n)`` convergence of
421    Monte Carlo estimates.
422
423    Parameters
424    ----------
425    values : array_like
426        Sample of an output (finite values).
427    percentiles : tuple of float, default (5, 50, 95)
428        Percentiles to report.
429
430    Returns
431    -------
432    dict
433        ``n``, ``mean``, ``sd``, ``sem`` and ``p<percentile>`` for each percentile.
434
435    Raises
436    ------
437    ValueError
438        If ``values`` is empty or contains non-finite entries.
439    """
440    v = np.asarray(values, dtype=np.float64).ravel()
441    if v.size == 0 or not np.all(np.isfinite(v)):
442        raise ValueError("values must be a non-empty array of finite numbers")
443    sd = float(v.std(ddof=1)) if v.size > 1 else 0.0
444    out = {"n": float(v.size), "mean": float(v.mean()), "sd": sd, "sem": sd / np.sqrt(v.size)}
445    out.update({f"p{p:g}": float(np.percentile(v, p)) for p in percentiles})
446    return out

453def aggregate_occupancy(occupancy: np.ndarray, factor: int) -> np.ndarray:
454    """Average consecutive blocks of ``factor`` steps (a coarser grid).
455
456    Each 1-minute value is already an exact time-average, so the block mean
457    is the exact time-average over the coarser bin, and person-time is
458    conserved. An incomplete final block is dropped.
459
460    Parameters
461    ----------
462    occupancy : array_like
463        People per step on the fine grid.
464    factor : int
465        Number of fine steps per coarse step.
466
467    Returns
468    -------
469    numpy.ndarray
470        Block means, length ``len(occupancy) // factor``.
471
472    Raises
473    ------
474    ValueError
475        If ``factor`` is not a positive integer or exceeds the series length.
476    """
477    occ = np.asarray(occupancy, dtype=np.float64)
478    if not isinstance(factor, (int, np.integer)) or not 1 <= factor <= occ.size:
479        raise ValueError(f"factor must be an integer in [1, {occ.size}], got {factor!r}")
480    n = occ.size // factor
481    return occ[: n * factor].reshape(n, factor).mean(axis=1)

178        self,
179        criterion: str,
180        ventilation_lps: np.ndarray | float,
181        volume_m3: np.ndarray | float,
182        co2_generation_lps: np.ndarray | float,
183        outdoor_co2_ppm: np.ndarray | float,
184        count_factor: np.ndarray | float = 1.0,
185    ) -> np.ndarray:
186        """Metric [ppm] for constant flow ``Q``, interpolating ``log M`` against ``log a``.
187
188        Parameters
189        ----------
190        criterion : {"8h", "peak"}
191            Which metric.
192        ventilation_lps : float or array_like
193            Constant flow ``Q`` [L/s].
194        volume_m3, co2_generation_lps, outdoor_co2_ppm, count_factor
195            As for :func:`scaled_metric`. Arrays broadcast.
196
197        Returns
198        -------
199        numpy.ndarray
200            Worst 8-hour mean or peak CO2 [ppm].
201
202        Raises
203        ------
204        ValueError
205            If any ``Q/V`` lies outside the tabulated range (no extrapolation).
206        """
207        v = self._check(criterion)
208        a = np.asarray(ventilation_lps, dtype=np.float64) / np.asarray(volume_m3, dtype=np.float64)
209        if np.any(a < self.a[0]) or np.any(a > self.a[-1]):
210            raise ValueError(f"Q/V outside the tabulated range [{self.a[0]:.3g}, {self.a[-1]:.3g}]")
211        m = np.exp(np.interp(np.log(a), np.log(self.a), np.log(v)))

214    def q_min(
215        self,
216        criterion: str,
217        volume_m3: np.ndarray | float,
218        co2_generation_lps: np.ndarray | float,
219        outdoor_co2_ppm: np.ndarray | float,
220        count_factor: np.ndarray | float = 1.0,
221        limit_ppm: float | None = None,
222    ) -> np.ndarray:
223        """Minimum constant flow ``Q_min`` [L/s] for each set of inputs (arrays broadcast).
224
225        Solves ``M(a) = (limit - C_out) V / (k G)`` by inverse interpolation of
226        the tabulated, strictly decreasing ``M(a)``, then ``Q_min = a V``.
227
228        Parameters
229        ----------
230        criterion : {"8h", "peak"}
231            Which metric must meet its limit.
232        volume_m3, co2_generation_lps, outdoor_co2_ppm, count_factor
233            As for :func:`scaled_metric`. Arrays broadcast.
234        limit_ppm : float, optional
235            Overrides the criterion's default limit (850 or 1000 ppm).
236
237        Returns
238        -------
239        numpy.ndarray
240            ``Q_min`` [L/s] for each set of inputs.
241
242        Raises
243        ------
244        ValueError
245            If ``limit <= C_out`` for any sample, or the required ``M`` lies
246            outside the tabulated range (no extrapolation).
247        """
248        v = self._check(criterion)
249        limit = CRITERIA[criterion][1] if limit_ppm is None else float(limit_ppm)
250        c_out = np.asarray(outdoor_co2_ppm, dtype=np.float64)
251        if np.any(c_out >= limit):
252            raise ValueError("the limit must exceed the outdoor CO2 concentration")
253        target = (limit - c_out) * np.asarray(volume_m3) / (np.asarray(count_factor) * np.asarray(co2_generation_lps))
254        if np.any(target > v[0]) or np.any(target < v[-1]):
255            raise ValueError("required unit metric outside the tabulated range; widen a_grid")
256        # np.interp needs increasing x: M is decreasing, so reverse both arrays.
257        log_a = np.interp(np.log(target), np.log(v[::-1]), np.log(self.a[::-1]))
258        return np.exp(log_a) * np.asarray(volume_m3, dtype=np.float64)

270    """One-at-a-time sensitivity of ``f`` over a low/high range for each input.
271
272    Parameters
273    ----------
274    f : callable
275        ``f(**inputs) -> float``. Called with every key of ``nominal``.
276    nominal : mapping
277        Nominal value of every input.
278    ranges : mapping
279        ``{name: (low, high)}`` for the inputs to vary (a subset of ``nominal``).
280
281    Returns
282    -------
283    pandas.DataFrame
284        One row per varied input, sorted by decreasing swing, with columns

287
288    Raises
289    ------
290    KeyError
291        If a range is given for an input that is not in ``nominal``.
292    """
293    unknown = set(ranges) - set(nominal)
294    if unknown:
295        raise KeyError(f"ranges given for unknown inputs: {sorted(unknown)}")
296    f0 = float(f(**nominal))
297    rows = []

302                     "f_nominal": f0, "swing": abs(f_hi - f_lo)})
303    return pd.DataFrame(rows).sort_values("swing", ascending=False, kind="stable", ignore_index=True)

def elasticities( f: Callable[..., float], nominal: Mapping[str, float], names: list[str] | None = None, rel_step: float = 0.01) -> dict[str, float]: 
306def elasticities(
307    f: Callable[..., float],
308    nominal: Mapping[str, float],
309    names: list[str] | None = None,
310    rel_step: float = 0.01,
311) -> dict[str, float]:
312    """Normalised local sensitivities ``(x / f) df/dx`` by central differences.
313
314    An elasticity of ``e`` means a 1 % change in the input changes the output
315    by about ``e`` %. Inputs with very different units can then be compared.
316    For a power law ``f = c x^p`` the elasticity is ``p``; the central
317    difference has an ``O(rel_step^2)`` error.
318
319    Parameters
320    ----------
321    f : callable
322        ``f(**inputs) -> float``.
323    nominal : mapping
324        Nominal inputs (non-zero for the inputs differentiated).
325    names : list of str, optional
326        Inputs to differentiate. Defaults to all of ``nominal``.
327    rel_step : float, default 0.01
328        Relative perturbation ``h``: inputs are set to ``x (1 +/- h)``.
329
330    Returns
331    -------
332    dict of str to float
333        Elasticity of ``f`` with respect to each input in ``names``.
334
335    Raises
336    ------
337    ValueError
338        If ``rel_step`` is not in (0, 0.5), or ``f`` or an input is zero at
339        the nominal point.
340    """
341    if not 0 < rel_step < 0.5:
342        raise ValueError("rel_step must be in (0, 0.5)")
343    f0 = float(f(**nominal))
344    if f0 == 0:
345        raise ValueError("f is zero at the nominal point; elasticity undefined")
346    out = {}
347    for name in names or list(nominal):
348        x = float(nominal[name])
349        if x == 0:
350            raise ValueError(f"input {name!r} is zero; elasticity undefined")
351        f_up = float(f(**{**nominal, name: x * (1 + rel_step)}))
352        f_dn = float(f(**{**nominal, name: x * (1 - rel_step)}))
353        out[name] = (f_up - f_dn) / (2 * rel_step * f0)
354    return out

361def sample_inputs(
362    distributions: Mapping[str, tuple],
363    n: int,
364    seed: int | None = 0,
365) -> dict[str, np.ndarray]:
366    """Draw ``n`` independent samples of each input.
367
368    Parameters
369    ----------
370    distributions : mapping
371        ``{name: (kind, *params)}`` with ``kind`` one of
372        ``("uniform", low, high)``, ``("loguniform", low, high)``,
373        ``("triangular", low, mode, high)`` or ``("normal", mean, sd)``.
374    n : int
375        Number of samples (> 0).
376    seed : int or None, default 0
377        Seed of :func:`numpy.random.default_rng`, for reproducibility.
378
379    Returns
380    -------
381    dict of str to numpy.ndarray
382
383    Raises
384    ------
385    ValueError
386        For an unknown distribution, the wrong number of parameters, or
387        invalid parameters.
388    """
389    if not isinstance(n, (int, np.integer)) or n < 1:
390        raise ValueError(f"n must be a positive integer, got {n!r}")
391    rng = np.random.default_rng(seed)
392    out = {}
393    for name, spec in distributions.items():
394        kind, *p = spec
395        if kind not in DISTRIBUTIONS:
396            raise ValueError(f"{name}: unknown distribution {kind!r}; use one of {sorted(DISTRIBUTIONS)}")
397        if len(p) != len(DISTRIBUTIONS[kind]):
398            raise ValueError(f"{name}: {kind} needs parameters {DISTRIBUTIONS[kind]}, got {p}")
399        if kind in ("uniform", "loguniform") and not p[0] < p[1]:
400            raise ValueError(f"{name}: need low < high")
401        if kind == "loguniform":
402            if p[0] <= 0:
403                raise ValueError(f"{name}: loguniform needs low > 0")
404            out[name] = np.exp(rng.uniform(np.log(p[0]), np.log(p[1]), n))
405        elif kind == "uniform":
406            out[name] = rng.uniform(p[0], p[1], n)
407        elif kind == "triangular":
408            if not p[0] <= p[1] <= p[2] or p[0] == p[2]:
409                raise ValueError(f"{name}: need low <= mode <= high and low < high")
410            out[name] = rng.triangular(p[0], p[1], p[2], n)
411        else:
412            if p[1] <= 0:
413                raise ValueError(f"{name}: normal needs sd > 0")
414            out[name] = rng.normal(p[0], p[1], n)
415    return out

423
424    Parameters
425    ----------

428    percentiles : tuple of float, default (5, 50, 95)
