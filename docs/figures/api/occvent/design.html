occvent.design

Ventilation design: compliance checks, minimum ventilation rates and energy.

This module answers the project's engineering questions:

  1. Compliance: for a given outdoor-air supply Q (constant, or varying in time), what are the 8-hour mean CO2, the peak and the time above limits?
  2. Minimum ventilation rate: the smallest constant Q meeting a CO2 criterion. This is a scalar root-finding problem F(Q) = metric(C(t; Q)) - limit = 0, where every evaluation of F solves the CO2 ODE. It has the same structure as the shooting method (MMA3001 Notebook 9.4): guess a parameter, integrate the ODE, measure the miss, and update the guess.
  3. Demand-controlled ventilation (DCV): supply that follows the measured occupancy, Q(t) = max(Q_floor, q_p * N(t)), and the smallest per-person rate q_p that meets the criterion.
  4. Energy: outdoor-air volume and the thermal energy needed to condition it.

Monotonicity (why bracketing root-finders are safe here)

With C >= C_out, raising Q at any instant can only lower C. The sensitivity S = dC/dQ obeys V dS/dt = (C_out - C) - Q S with S(0) = 0, and its forcing C_out - C <= 0, so S <= 0 for all t. Every metric used here (8-h mean, peak) is therefore non-increasing in Q (and in q_p for DCV). F has at most one sign change, so bisection always converges once a bracket is found.

Root finders are implemented from scratch (bisection; secant safeguarded by a bracket) and recorded iteration by iteration, so their convergence can be compared. SciPy's brentq serves as an independent cross-check in the notebook.

 93class RootResult:
 94    """Outcome of a root-finding run.
 95
 96    Attributes
 97    ----------
 98    root : float
 99        Final estimate of ``x`` with ``f(x) = 0``.
100    f_root : float
101        ``f(root)``.
102    converged : bool
103        Whether a stopping tolerance was met within ``max_iter``.
104    evaluations : int
105        Number of calls to ``f``, including the two bracket ends. Each call is
106        one full ODE solve.
107    method : str
108        ``"bisection"`` or ``"secant"``.
109    history : list of (float, float)
110        Every ``(x, f(x))`` evaluated, in order.
111    """
112
113    root: float
114    f_root: float
115    converged: bool
116    evaluations: int
117    method: str
118    history: list[tuple[float, float]] = field(default_factory=list)

121def _check_bracket(f: Callable[[float], float], lo: float, hi: float) -> tuple[float, float]:
122    """Evaluate ``f`` at both ends and check that they have opposite signs."""
123    if not (np.isfinite(lo) and np.isfinite(hi)) or lo >= hi:
124        raise ValueError(f"need a finite bracket with lo < hi, got ({lo}, {hi})")
125    f_lo, f_hi = float(f(lo)), float(f(hi))
126    if not (np.isfinite(f_lo) and np.isfinite(f_hi)):
127        raise ValueError("f is not finite at the bracket ends")
128    if f_lo * f_hi > 0:
129        raise ValueError(f"f(lo)={f_lo:.4g} and f(hi)={f_hi:.4g} have the same sign: the bracket does not contain a root")
130    return f_lo, f_hi

133def bisection(
134    f: Callable[[float], float],
135    lo: float,
136    hi: float,
137    x_tol: float = 1e-2,
138    f_tol: float = 1e-2,
139    max_iter: int = 200,
140) -> RootResult:
141    """Find a root of ``f`` in ``[lo, hi]`` by bisection.
142
143    Each iteration halves the bracket, so the error after ``n`` iterations is
144    at most ``(hi - lo) / 2**n``. This is linear convergence with ratio 1/2,
145    guaranteed for any continuous ``f`` that changes sign on the bracket.
146
147    Parameters
148    ----------
149    f : callable
150        Continuous scalar function.
151    lo, hi : float
152        Bracket ends with ``f(lo) * f(hi) <= 0``.
153    x_tol : float, default 0.01
154        Stop when the bracket is narrower than this (same units as ``x``).
155    f_tol : float, default 0.01
156        Stop when ``|f(x)| <= f_tol`` (same units as ``f``).
157    max_iter : int, default 200
158        Maximum number of bisection steps.
159
160    Returns
161    -------
162    RootResult
163
164    Raises
165    ------
166    ValueError
167        If the bracket is invalid or does not contain a sign change.
168    """
169    f_lo, f_hi = _check_bracket(f, lo, hi)
170    history = [(lo, f_lo), (hi, f_hi)]
171    if f_lo == 0 or f_hi == 0:
172        x = lo if f_lo == 0 else hi
173        return RootResult(x, 0.0, True, 2, "bisection", history)
174    for _ in range(max_iter):
175        mid = 0.5 * (lo + hi)
176        f_mid = float(f(mid))
177        history.append((mid, f_mid))
178        if abs(f_mid) <= f_tol or (hi - lo) <= x_tol:
179            return RootResult(mid, f_mid, True, len(history), "bisection", history)
180        if np.sign(f_mid) == np.sign(f_lo):
181            lo, f_lo = mid, f_mid
182        else:
183            hi, f_hi = mid, f_mid
184    return RootResult(mid, f_mid, False, len(history), "bisection", history)

187def secant_bracketed(
188    f: Callable[[float], float],
189    lo: float,
190    hi: float,
191    x_tol: float = 1e-2,
192    f_tol: float = 1e-2,
193    max_iter: int = 100,
194) -> RootResult:
195    """Find a root of ``f`` in ``[lo, hi]`` by the secant method, safeguarded by bisection.
196
197    The secant method is Newton's method with the derivative replaced by the
198    slope through the last two iterates::
199
200        x_new = x1 - f1 * (x1 - x0) / (f1 - f0)
201
202    It needs no derivative (useful here, because each ``f`` is a whole ODE
203    solve) and converges superlinearly (order about 1.618) near a simple root.
204    On its own it can jump out of the region where the root lies. A sign-
205    change bracket is therefore kept: any secant step that would leave the
206    bracket, or that cannot be computed, is replaced by a bisection step. This
207    guarantees convergence.
208
209    Parameters and return value are as for :func:`bisection`. Iteration also
210    stops when successive iterates differ by less than ``x_tol``.
211    """
212    f_lo, f_hi = _check_bracket(f, lo, hi)
213    history = [(lo, f_lo), (hi, f_hi)]
214    if f_lo == 0 or f_hi == 0:
215        x = lo if f_lo == 0 else hi
216        return RootResult(x, 0.0, True, 2, "secant", history)
217    a, fa, b, fb = lo, f_lo, hi, f_hi          # sign-change bracket
218    x0, f0, x1, f1 = lo, f_lo, hi, f_hi        # last two iterates
219    for _ in range(max_iter):
220        denom = f1 - f0
221        x2 = x1 - f1 * (x1 - x0) / denom if denom != 0 else np.nan
222        if not (np.isfinite(x2) and a < x2 < b):
223            x2 = 0.5 * (a + b)                 # safeguard: bisection step
224        f2 = float(f(x2))
225        history.append((x2, f2))
226        if abs(f2) <= f_tol or abs(x2 - x1) <= x_tol or (b - a) <= x_tol:
227            return RootResult(x2, f2, True, len(history), "secant", history)
228        if np.sign(f2) == np.sign(fa):
229            a, fa = x2, f2
230        else:
231            b, fb = x2, f2
232        x0, f0, x1, f1 = x1, f1, x2, f2
233    return RootResult(x2, f2, False, len(history), "secant", history)
234

236ROOT_FINDERS: dict[str, Callable[..., RootResult]] = {
237    "bisection": bisection,
238    "secant": secant_bracketed,
239}

242def _solve_monotone_decreasing(
243    F: Callable[[float], float],
244    lo: float,
245    hi: float,
246    method: str,
247    x_tol: float,
248    f_tol: float,
249    max_expand: int = 20,
250    variable: str = "direct",
251) -> RootResult:
252    """Root of a non-increasing ``F``. Expands ``hi`` (doubling) until ``F(hi) <= 0``.
253
254    With ``variable="inverse"`` the root finder works in ``u = 1/x`` instead of
255    ``x``. CO2 above outdoor level scales roughly as ``1/Q`` (``C_ss - C_out =
256    1e6 G N / Q``), so ``F`` is nearly *linear* in ``1/Q``. Secant steps are
257    then almost exact. The returned ``root`` and ``history`` are always in
258    terms of ``x``. ``x_tol`` applies to ``x``: it is converted to an
259    equivalent tolerance on ``u`` near the upper end of the bracket.
260    """
261    if variable not in ("direct", "inverse"):
262        raise ValueError(f"variable must be 'direct' or 'inverse', got {variable!r}")
263    if method not in ROOT_FINDERS:
264        raise ValueError(f"method must be one of {sorted(ROOT_FINDERS)}, got {method!r}")
265    if lo <= 0 or hi <= lo:
266        raise ValueError(f"need 0 < lo < hi, got ({lo}, {hi})")
267    cache: dict[float, float] = {}
268    F_raw = F
269
270    def F(x: float) -> float:  # memoised: each ODE solve is done once per x
271        if x not in cache:
272            cache[x] = float(F_raw(x))
273        return cache[x]
274
275    if F(lo) <= 0:
276        raise ValueError(f"the criterion is already met at the lower bound {lo}; lower it")
277    for _ in range(max_expand):
278        if F(hi) <= 0:
279            break
280        hi *= 2.0
281    else:
282        raise ValueError("could not find an upper bound that meets the criterion")
283    if variable == "direct":
284        return ROOT_FINDERS[method](F, lo, hi, x_tol=x_tol, f_tol=f_tol)
285    # u = 1/x reverses the bracket order; F(1/u) is non-decreasing in u.
286    u_tol = x_tol / hi**2          # |du| = |dx| / x^2, conservative at the largest x
287    res = ROOT_FINDERS[method](lambda u: F(1.0 / u), 1.0 / hi, 1.0 / lo, x_tol=u_tol, f_tol=f_tol)
288    res.root = 1.0 / res.root
289    res.history = [(1.0 / u, f) for u, f in res.history]
290    res.method = f"{res.method} (1/x)"
291    return res

294def _criterion(criterion: str, limit_ppm: float | None) -> tuple[str, float]:
295    if criterion not in CRITERIA:
296        raise ValueError(f"criterion must be one of {sorted(CRITERIA)}, got {criterion!r}")

301def find_min_ventilation(
302    occupancy: np.ndarray,
303    params: RoomParameters,
304    dt_s: float,
305    criterion: str = "8h",
306    limit_ppm: float | None = None,
307    bracket_lps: tuple[float, float] = (1.0, 1000.0),
308    method: str = "secant",
309    x_tol: float = 0.01,
310    f_tol: float = 0.01,
311    variable: str = "direct",
312) -> RootResult:
313    """Smallest constant outdoor-air flow ``Q`` [L/s] that meets a CO2 criterion.
314
315    Solves ``F(Q) = metric(Q) - limit = 0`` (see the module docstring for why
316    ``F`` is non-increasing in ``Q``).
317
318    Parameters
319    ----------
320    occupancy : array_like
321        People per step over the assessment period (at least 8 hours).
322    params : RoomParameters
323        Model parameters.
324    dt_s : float
325        Step length [s].
326    criterion : {"8h", "peak"}, default "8h"
327        ``"8h"``: worst 8-hour mean CO2 (NCC limit 850 ppm by default).
328        ``"peak"``: worst step-mean CO2 (1000 ppm by default).
329    limit_ppm : float, optional
330        Overrides the criterion's default limit.
331    bracket_lps : (float, float), default (1, 1000)
332        Starting bracket. The upper end is doubled automatically until the
333        criterion is met.
334    method : {"secant", "bisection"}, default "secant"
335        Root finder.
336    x_tol : float, default 0.01
337        Tolerance on ``Q`` [L/s].
338    f_tol : float, default 0.01
339        Tolerance on the metric [ppm].
340    variable : {"direct", "inverse"}, default "direct"
341        Root-find in ``Q`` or in ``1/Q``. ``"inverse"`` makes ``F`` nearly
342        linear, so the secant method converges in fewer ODE solves.
343
344    Returns
345    -------
346    RootResult
347        ``root`` is ``Q_min`` [L/s]. ``history`` holds every ``(Q, F)`` tried.
348
349    Raises
350    ------
351    ValueError
352        For an unknown criterion or method, or if the criterion is already
353        met at the lower bracket end.
354    """
355    key, limit = _criterion(criterion, limit_ppm)
356    occ, _ = validate_inputs(occupancy, 1.0, dt_s)
357
358    def F(q: float) -> float:
359        # Compliance function: positive = too little air, zero at Q_min (one ODE solve per call).
360        return evaluate_ventilation(occ, q, params, dt_s)[key] - limit
361
362    return _solve_monotone_decreasing(F, bracket_lps[0], bracket_lps[1], method, x_tol, f_tol,
363                                      variable=variable)

370def dcv_ventilation(
371    occupancy: np.ndarray,
372    q_per_person_lps: float,
373    q_floor_lps: float,
374    q_cap_lps: float | None = None,
375) -> np.ndarray:
376    """Demand-controlled supply ``Q(t) = min(Q_cap, max(Q_floor, q_p * N(t)))`` [L/s].
377
378    This is an idealised controller that responds instantly to the measured
379    count. The floor keeps a minimum flow when the room is empty or lightly
380    used, so CO2 (and other pollutants) can still be flushed out. The optional
381    cap represents the maximum capacity of the fan or air-handling unit.
382
383    Parameters
384    ----------
385    occupancy : array_like
386        People per step (measured or forecast).
387    q_per_person_lps : float
388        Outdoor air per person ``q_p`` [L/s per person], >= 0.
389    q_floor_lps : float
390        Minimum flow ``Q_floor`` [L/s], >= 0.
391    q_cap_lps : float, optional
392        Maximum flow ``Q_cap`` [L/s], >= ``q_floor_lps``. ``None`` means no cap.
393
394    Returns
395    -------
396    numpy.ndarray
397        Flow [L/s] for every step.
398
399    Raises
400    ------
401    ValueError
402        If a rate is negative, or the cap is below the floor.
403    """
404    if q_per_person_lps < 0 or q_floor_lps < 0:
405        raise ValueError("q_per_person_lps and q_floor_lps must be non-negative")
406    if q_cap_lps is not None and q_cap_lps < q_floor_lps:
407        raise ValueError("q_cap_lps must be at least q_floor_lps")
408    occ = np.asarray(occupancy, dtype=np.float64)
409    q = np.maximum(q_floor_lps, q_per_person_lps * occ)
410    return q if q_cap_lps is None else np.minimum(q, q_cap_lps)

413def find_min_dcv_rate(
414    occupancy: np.ndarray,
415    params: RoomParameters,
416    dt_s: float,
417    q_floor_lps: float,
418    q_cap_lps: float | None = None,
419    criterion: str = "8h",
420    limit_ppm: float | None = None,
421    bracket_lps_per_person: tuple[float, float] = (0.1, 50.0),
422    method: str = "secant",
423    x_tol: float = 1e-3,
424    f_tol: float = 0.01,
425) -> RootResult:
426    """Smallest per-person DCV rate ``q_p`` [L/s per person] that meets a CO2 criterion.
427
428    ``Q(t) = min(q_cap, max(q_floor, q_p N(t)))`` never decreases at any
429    instant as ``q_p`` rises, so the metric is non-increasing in ``q_p`` and
430    bracketing applies. Parameters and return value are as for
431    :func:`find_min_ventilation`, with ``root`` in L/s per person. If a cap is
432    set and the criterion cannot be met even at the bracket's upper end, a
433    ``ValueError`` is raised.
434    """
435    key, limit = _criterion(criterion, limit_ppm)
436    occ, _ = validate_inputs(occupancy, 1.0, dt_s)
437
438    def F(qp: float) -> float:
439        # Same compliance function, but for the DCV per-person rate q_p.
440        q = dcv_ventilation(occ, qp, q_floor_lps, q_cap_lps)
441        return evaluate_ventilation(occ, q, params, dt_s)[key] - limit
442
443    return _solve_monotone_decreasing(F, bracket_lps_per_person[0], bracket_lps_per_person[1],
444                                      method, x_tol, f_tol)

451def outdoor_air_energy(
452    ventilation_lps: np.ndarray | float,
453    dt_s: float,
454    n_steps: int,
455    delta_t_k: float,
456    rho_cp_kj_per_m3k: float = RHO_CP_AIR_KJ_PER_M3K,
457) -> dict[str, float]:
458    """Outdoor-air volume and the sensible energy needed to condition it.
459
460    ``E = rho c_p * integral(Q dt) * dT``. Because ``Q`` is constant within each
461    step, the integral is the exact sum ``sum(Q_i dt)``: the rectangle rule is
462    exact for a piecewise-constant integrand (Week 6).
463
464    Parameters
465    ----------
466    ventilation_lps : float or array_like
467        Flow [L/s], constant or one value per step.
468    dt_s : float
469        Step length [s].
470    n_steps : int
471        Number of steps (used when ``ventilation_lps`` is a constant).
472    delta_t_k : float
473        Representative magnitude of the indoor–outdoor temperature difference
474        [K] (an assumption; no outdoor temperature data are available).
475    rho_cp_kj_per_m3k : float, default 1.206
476        Volumetric heat capacity of air [kJ/(m3 K)].
477
478    Returns
479    -------
480    dict
481        ``air_volume_m3`` and ``energy_kwh``.
482
483    Raises
484    ------
485    ValueError
486        For negative flows or temperature difference, non-positive ``dt_s``,
487        or a length mismatch.
488    """
489    q = np.asarray(ventilation_lps, dtype=np.float64)
490    if q.ndim == 0:
491        q = np.full(int(n_steps), float(q))
492    if q.size != n_steps:
493        raise ValueError(f"ventilation has {q.size} values but n_steps={n_steps}")
494    if np.any(q < 0) or delta_t_k < 0 or dt_s <= 0:
495        raise ValueError("flows and delta_t_k must be non-negative and dt_s positive")
496    volume = float(np.sum(q) / 1000.0 * dt_s)
497    energy_kwh = volume * rho_cp_kj_per_m3k * delta_t_k / 3600.0
498    return {"air_volume_m3": volume, "energy_kwh": energy_kwh}

189    f: Callable[[float], float],
190    lo: float,

192    x_tol: float = 1e-2,
193    f_tol: float = 1e-2,
194    max_iter: int = 100,
195) -> RootResult:
196    """Find a root of ``f`` in ``[lo, hi]`` by the secant method, safeguarded by bisection.
197
198    The secant method is Newton's method with the derivative replaced by the
199    slope through the last two iterates::
200
201        x_new = x1 - f1 * (x1 - x0) / (f1 - f0)
202
203    It needs no derivative (useful here, because each ``f`` is a whole ODE
204    solve) and converges superlinearly (order about 1.618) near a simple root.
205    On its own it can jump out of the region where the root lies. A sign-
206    change bracket is therefore kept: any secant step that would leave the
207    bracket, or that cannot be computed, is replaced by a bisection step. This
208    guarantees convergence.
209
210    Parameters and return value are as for :func:`bisection`. Iteration also
211    stops when successive iterates differ by less than ``x_tol``.
212    """
213    f_lo, f_hi = _check_bracket(f, lo, hi)
214    history = [(lo, f_lo), (hi, f_hi)]
215    if f_lo == 0 or f_hi == 0:
216        x = lo if f_lo == 0 else hi
217        return RootResult(x, 0.0, True, 2, "secant", history)
218    a, fa, b, fb = lo, f_lo, hi, f_hi          # sign-change bracket
219    x0, f0, x1, f1 = lo, f_lo, hi, f_hi        # last two iterates
220    for _ in range(max_iter):
221        denom = f1 - f0
222        x2 = x1 - f1 * (x1 - x0) / denom if denom != 0 else np.nan
223        if not (np.isfinite(x2) and a < x2 < b):
224            x2 = 0.5 * (a + b)                 # safeguard: bisection step
225        f2 = float(f(x2))
226        history.append((x2, f2))
227        if abs(f2) <= f_tol or abs(x2 - x1) <= x_tol or (b - a) <= x_tol:
228            return RootResult(x2, f2, True, len(history), "secant", history)
229        if np.sign(f2) == np.sign(fa):
230            a, fa = x2, f2
231        else:
232            b, fb = x2, f2
233        x0, f0, x1, f1 = x1, f1, x2, f2
234    return RootResult(x2, f2, False, len(history), "secant", history)
